# Crédito Hipotecario

## Local development

Requires Node.js & npm - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

```sh
# Step 1: Clone the repository.
git clone https://github.com/elbenja/credito-hipotecario.git

# Step 2: Navigate to the project directory.
cd credito-hipotecario

# Step 3: Install the necessary dependencies.
npm i

# Step 4: Copy .env.example to .env and fill in the values.
cp .env.example .env

# Step 5: Start the development server.
npm run dev
```

## Technologies

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
